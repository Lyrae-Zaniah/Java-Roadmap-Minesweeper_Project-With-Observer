# Campo Minado em Java com Observer Pattern

Implementação do jogo Campo Minado em Java utilizando o padrão de projeto Observer, 
promovendo baixo acoplamento entre a lógica do jogo e os componentes observadores.

##  Destaques da Arquitetura
- Uso do padrão Observer para notificação de mudanças de estado
- Separação clara entre domínio e interface
- Código extensível e de fácil manutenção
- Testes automatizados com JUnit 5

##  Tecnologias
- Java 17
- JUnit 5
- Maven
- Git

##  Conceitos aplicados
- Object-Oriented Programming (OOP)
- Observer Design Pattern
- Clean Code
- Unit Testing
